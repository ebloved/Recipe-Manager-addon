🔑 Как получить ключ LLM

      
    

    


      

        LLM — это нейросеть, которая пишет и разбирает текст. Recipe Manager
        использует её для генерации рецептов, импорта из YouTube и сайтов,
        пересчёта под аэрогриль, оценки активного времени, разбора голосового
        текста и подсказок по продуктам.
      


      

        ❓ Зачем мне свой ключ, если всё и так работает?
        
Без ключа приложение использует резервные ключи администратора:
        5 бесплатных запросов в день на пользователя. Это нормально,
        чтобы попробовать, но на активную работу лимита не хватит.

        
Свой ключ даёт:

        
    
          
  • личный дневной лимит — не делите с другими пользователями;
    • 
          
  • больше генераций — рецепты, YouTube, аэрогриль, голос, оценка времени;
    • 
          
  • скорость — можно выбрать быстрый сервис;
    • 
          
  • независимость — ваши запросы не упираются в чужие;
    • 
          
  • контроль — ключ шифруется, хранится в SQLite и удаляется одной кнопкой.
    • 
        

        
Ключ не обязателен. Начните с Gemini: это бесплатно и проще всего.

      


      

        ✨ Gemini — самый простой бесплатный старт
        
    
          
  1. Откройте Google AI Studio.
    2. 
          
  2. Войдите в свой Google-аккаунт.
    3. 
          
  3. Нажмите Create API key или Get API key.
    4. 
          
  4. Выберите существующий проект или создайте новый.
    5. 
          
  5. Скопируйте ключ. Он начинается на AIza....
    6. 
          
  6. Вернитесь в Кабинет → LLM-провайдеры → Gemini.
    7. 
          
  7. Вставьте ключ в поле API Key и нажмите Сохранить ключи.
    8. 
        

        
Плюсы: бесплатный лимит и не нужна банковская карта.
        Минусы: медленнее и лимит может закончиться. Если видите ошибку
        429 — это дневной лимит Gemini, попробуйте позже.

      


      

        ⚡ OrcaRouter — быстрее
        
    
          
  1. Откройте orcarouter.ai и зарегистрируйтесь.
    2. 
          
  2. В личном кабинете найдите раздел API Keys.
    3. 
          
  3. Создайте ключ и скопируйте его. Обычно он начинается на sk-orca-....
    4. 
          
  4. Вставьте ключ в поле OrcaRouter и нажмите Сохранить ключи.
    5. 
        

        
Подходит, если важна скорость. У OrcaRouter могут быть свои
        лимиты и платные тарифы — проверьте условия на сайте.

      


      

        🔧 Custom AI — свой провайдер или локальная модель
        
Этот вариант для тех, у кого уже есть OpenAI-совместимый
        сервис: OpenAI, OpenRouter, Groq, Ollama и подобные.

        
    
          
  1. Возьмите Base URL, который заканчивается на /v1.
          Примеры: https://api.openai.com/v1,
          https://openrouter.ai/api/v1,
          http://localhost:11434/v1 для Ollama.
    2. 
          
  2. Вставьте API Key из личного кабинета провайдера.
          Для локальной Ollama ключ часто не нужен — можно оставить пустым
          или указать любой.
    3. 
          
  3. Укажите модель, например gpt-4o-mini или
          llama3.1. Кнопка Загрузить попробует получить
          список моделей с сервера.
    4. 
          
  4. Нажмите Сохранить ключи.
    5. 
        

        
Важно: приложение отправит текст рецепта на указанный адрес.
        Используйте только сервис, которому доверяете.

      


      

        💾 Как сохранить и проверить
        
    
          
  1. Откройте Кабинет → LLM-провайдеры.
    2. 
          
  2. Вставьте ключ в нужное поле. Можно заполнить один, два или все три.
    3. 
          
  3. Нажмите Сохранить ключи. Приложение проверит новые ключи.
    4. 
          
  4. Зелёная надпись «сохранён» — ключ принят. Красная/жёлтая —
          проверьте ключ, лимит или интернет.
    5. 
        

        
Порядок выбора: Custom → OrcaRouter → Gemini → резервный Gemini → Hermes.
        Используется первый рабочий вариант. Если ключ не сработал,
        приложение попробует следующий, а в крайнем случае — резервный
        лимит администратора.

      


      

        🔒 Безопасность и деньги
        
    
          
  • Ключи хранятся в зашифрованном виде в SQLite и не показываются
          после сохранения — только маска.
    • 
          
  • Ключ используется только для ваших запросов.
    • 
          
  • Никому не передавайте ключ. Если он попал не туда — удалите его
          в Кабинете и создайте новый у провайдера.
    • 
          
  • Приложение не списывает деньги. Лимиты и оплата — у выбранного
          провайдера. Бесплатные тарифы могут иметь дневные ограничения.
    • 
          
  • Кнопка 🗑️ рядом с полем удаляет ключ.
    • 
        

      


      

        🆘 Если ключ не работает
        
    
          
  • Проверьте, что ключ скопирован полностью, без пробелов и переносов.
    • 
          
  • Проверьте лимит и баланс в личном кабинете провайдера.
    • 
          
  • Для Custom AI проверьте URL (должен заканчиваться на /v1)
          и точное название модели.
    • 
          
  • Ошибка 429 — слишком много запросов или закончился дневной лимит.
          Подождите или используйте другой ключ/провайдер.
    • 
          
  • Если ничего не помогает — удалите ключ и создайте новый.
    •

        🚀 Быстрый старт
        
    
          
  1. Добавьте рецепт: вкладка «➕ Добавить» → YouTube / сайт / Markdown / вручную.
    2. 
          
  2. Проверьте ингредиенты: в карточке рецепта свяжите продукты — иконки ✅ / 🔗.

    4.

    5. 
          
  5. Готовьте: «🍳 На кухню» → выберите гарнир → отмечайте ингредиенты и шаги.
    6. 
        

      


      

        ➕ Как добавить рецепт
        
    
          
  • YouTube — вставьте ссылку на видео/Shorts. Транскрипт получает Apify, рецепт собирает LLM. Повторный импорт того же видео берётся из кэша и не тратит кредиты. При исчерпании лимита Apify кнопки скрываются. Обложка из видео не подставляется — фото добавляется вручную в редакторе. Полностью отключить: опция youtube_import_enabled.
    • 
          
  • С сайта — вставьте URL. Парсер ищет JSON-LD / microdata.
    • 
          
  • Markdown — файл с YAML front matter. Шаблон: app/recipe_template.md.
    • 
          
  • Вручную — откройте редактор и заполните название, ингредиенты, шаги, порции и время.
    • 
        

        
После сохранения рецепт появляется во вкладке «Рецепты». Его можно редактировать, скрывать, связывать продукты, добавлять в план и покупки.

        👤 Кабинет и LLM-ключи: зачем и как
        
LLM — это нейросеть, которая пишет и разбирает текст. Recipe Manager
        использует её для генерации рецептов, импорта из YouTube и сайтов,
        пересчёта под аэрогриль, оценки активного времени, разбора голосового
        текста и подсказок по продуктам.

        
Без своего ключа приложение работает на резервных ключах
        администратора: 5 бесплатных запросов в день на пользователя. Этого
        хватает, чтобы попробовать, но для регулярной работы лучше свой ключ.

        
Свой ключ даёт личный дневной лимит, больше генераций,
        скорость и независимость от чужих запросов. Ключ шифруется, хранится
        в SQLite и удаляется одной кнопкой.

        
Что выбрать:

    •

          (OpenAI, OpenRouter, Groq) или локальная модель вроде Ollama.
    •

        🧹 Нормализация рецептов
        
    
          
  • В фоне рецепты приводятся к стандарту: единицы, дубли, количества внутри имени, optional.
    • 
          
  • Ингредиенты связываются с продуктами локальным матчером.
    • 
          
  • На карточке: ✅ норма или ⚠️ N — N проблем. Наведите курсор, чтобы увидеть причины.
    • 
          
  • info — подсказка (нет КБЖУ, продукт не найден в базе), warning — стоит поправить, error — рецепт структурно неполный.
    • 
        

      


      

        ❓ Частые вопросы
        
    
          
  • Почему не собралась корзина? Проверьте «🏪 Магазины» → «Проверить». Если магазин не подключён — подключите OAuth.
    • 
          
  • Почему товар не найден? Его может не быть в ассортименте ВкусВилла. Посмотрите warnings и выберите замену.
    • 
          
  • Почему ⚠️ на рецепте? Откройте карточку — там список проблем. Часть исправляется автоматически, часть требует ручной правки.
    • 
          
  • Где хранятся данные? В /data: рецепты и JSON-бэкапы, SQLite rm.sqlite3, бэкапы миграций.
    • 
          
  • Как сбросить готовку? «✅ Завершить готовку» на экране «Готовлю сейчас».
