❓ Помощь по Recipe Manager

        
Основные функции, иконки и типовые сценарии

      

      
    

    


      

        🚀 Быстрый старт
        
    
          
  1. Добавьте рецепт: вкладка «➕ Добавить» → YouTube / сайт / Markdown / вручную.
    2. 
          
  2. Проверьте ингредиенты: в карточке рецепта свяжите продукты — иконки ✅ / 🔗.
    3. 
          
  3. Запланируйте: «📅 В план» на карточке или в деталях рецепта.
    4. 
          
  4. Соберите покупки: «🛒 В покупки», затем «🛒 Покупки» → «Собрать через …» (кнопки подключённых магазинов).
    5. 
          
  5. Готовьте: «🍳 На кухню» → выберите гарнир → отмечайте ингредиенты и шаги.
    6. 
        

      


      

        ➕ Как добавить рецепт
        
    
          
  • YouTube — вставьте ссылку на видео/Shorts. Транскрипт получает Apify, рецепт собирает LLM. Повторный импорт того же видео берётся из кэша и не тратит кредиты. При исчерпании лимита Apify кнопки скрываются. Обложка из видео не подставляется — фото добавляется вручную в редакторе. Полностью отключить: опция youtube_import_enabled.
    • 
          
  • С сайта — вставьте URL. Парсер ищет JSON-LD / microdata.
    • 
          
  • Markdown — файл с YAML front matter. Шаблон: app/recipe_template.md.
    • 
          
  • Вручную — откройте редактор и заполните название, ингредиенты, шаги, порции и время.
    • 
        

        
После сохранения рецепт появляется во вкладке «Рецепты». Его можно редактировать, скрывать, связывать продукты, добавлять в план и покупки.

В деталях рецепта можно масштабировать порции, переключать духовку/аэрогриль, оценить активное время и скрыть его. Кнопка «Поделиться» — внизу: она создаёт отдельную публичную страницу и показывает QR-код со ссылкой.

      


      

        🍳 Готовлю сейчас
        
    
          
  • Нажмите 🍳 На кухню на основном блюде. Можно сразу выбрать гарнир или нажать «Без гарнира».
    • 
          
  • Ингредиенты основного блюда и гарнира объединяются; дубликаты склеиваются.
    • 
          
  • Чек-лист синхронизируется с сервером — можно открыть на другом устройстве.
    • 
          
  • Шаги идут отдельными блоками: основное → разделитель → гарнир. Они не перемешиваются.
    • 
          
  • Кнопки ⏱ запускают таймер по времени из шага.
    • 
          
  • 📅 Отправить в Сегодня добавляет блюдо в план, 🛒 Отправить в покупки — неотмеченные ингредиенты в список.
    • 
          
  • ✅ Завершить готовку удаляет сессию и сбрасывает чек-лист.
    • 
        

      


      

        🛒 Покупки и магазины
        
    
          
  • «Покупки» — общий список; можно добавлять вручную, по штрихкоду, из рецепта и из готовки.
    • 
          
  • «Только активные» скрывает купленное; «Очистить купленные» удаляет отмеченные.
    • 
          
  • «🏪 Магазины» — подключение своего аккаунта ВкусВилла через OAuth. Токены хранятся на сервере в зашифрованном виде.
    • 
          
  • Кнопка «Собрать корзину» в магазине собирает корзину из активного списка: известные SKU идут fast path, новые — через MCP + LLM.
    • 
          
  • Предупреждения показывают, что не удалось найти или взвесить. Если товара нет в магазине — выберите замену вручную.
    • 
        

      


      

        📅 Планировщик
        
    
          
  • Сетка на неделю: завтрак, обед, перекус, ужин.
    • 
          
  • Клик по ячейке → выбор рецепта; можно указать порции.
    • 
          
  • «Готовлю сейчас → Отправить в Сегодня» добавляет основное и гарнир в план на текущий день.
    • 
        

      


      

        ✨ Генератор и профили
        
    
          
  • Выберите профиль (ограничения по калориям, времени, ингредиентам), тему и количество рецептов.
    • 
          
  • Используется LLM-каскад: Custom → Orca → Gemini → admin Gemini → Hermes.
    • 
          
  • Без своих ключей доступно 5 генераций в день на admin-ключах.
    • 
          
  • Профили создаются в Кабинете / разделе профилей.
    • 
        

      


      

        🧺 Продукты и связки
        
    
          
  • «Продукты» — база продуктов: названия, бренды, штрихкоды, алиасы, КБЖУ.
    • 
          
  • Связка ингредиента с продуктом улучшает подбор в покупках и магазинах.
    • 
          
  • В карточке рецепта: ✅ — связано, 🔗 — не связано, ❓ — продукт удалён.
    • 
          
  • Если у штучного продукта неизвестен вес, Кабинет → «⚖️ Веса продуктов» поможет.
    • 
        

      


      

        👤 Кабинет и LLM-ключи
        
    
          
  • Свои ключи: Custom AI (OpenAI-совместимый), OrcaRouter, Gemini.
    • 
          
  • Порядок: Custom → Orca → Gemini → admin Gemini → Hermes.
    • 
          
  • Ключи шифруются и хранятся в SQLite; кнопка 🗑️ удаляет ключ.
    • 
          
  • Админу доступны системные настройки, Telegram-уведомления, бэкап и синхронизация GitHub.
    • 
        

      


      

        🧹 Нормализация рецептов
        
    
          
  • В фоне рецепты приводятся к стандарту: единицы, дубли, количества внутри имени, optional.
    • 
          
  • Ингредиенты связываются с продуктами локальным матчером.
    • 
          
  • На карточке: ✅ норма или ⚠️ N — N проблем. Наведите курсор, чтобы увидеть причины.
    • 
          
  • info — подсказка (нет КБЖУ, продукт не найден в базе), warning — стоит поправить, error — рецепт структурно неполный.
    • 
        

      


      

        ❓ Частые вопросы
        
    
          
  • Почему не собралась корзина? Проверьте «🏪 Магазины» → «Проверить». Если магазин не подключён — подключите OAuth.
    • 
          
  • Почему товар не найден? Его может не быть в ассортименте ВкусВилла. Посмотрите warnings и выберите замену.
    • 
          
  • Почему ⚠️ на рецепте? Откройте карточку — там список проблем. Часть исправляется автоматически, часть требует ручной правки.
    • 
          
  • Где хранятся данные? В /data: рецепты и JSON-бэкапы, SQLite rm.sqlite3, бэкапы миграций.
    • 
          
  • Как сбросить готовку? «✅ Завершить готовку» на экране «Готовлю сейчас».
